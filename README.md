# odin-recipes

This project is a recipe website built as part of the Foundations course in The Odin Project (TOP).

## Structure

- An index page (`index.html`) listing all recipes
- Links to individual recipe pages (e.g., fried chicken, gyoza, ginger pork)
- Photos of the finished dishes
- Ingredients and preparation steps written in HTML

## Skills Demonstrated

- Basic HTML structure and semantics
- Creating internal links between pages
- Displaying images using `<img>`
- Version contrli and publishing using Git and GitHub

## Objectives

To practice and apply fundamental HTML skills by building and publishing a simple static website.  
Learning progress is documented in Notion to organize and retain knowledge for future use.
